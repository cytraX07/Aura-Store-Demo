HOW TO EXPLORE THE DEMO  (please use a phone as well as a laptop)
----------------------------------------------------------
The store is designed mobile-first, so what you see on your phone is
the real experience your customers will get.

  1. Product listing   – category filters, live search, sort by price
                         or rating, quick view on any product.
  2. Cart              – add products, change quantity, remove items.
                         A free-shipping progress bar appears as you
                         get closer to the threshold. The cart is
                         remembered if you refresh the page.
  3. Checkout          – fill in name, phone, PIN code and address,
                         then choose UPI / card / cash-on-delivery.
                         The form validates before it accepts an order.
  4. WhatsApp ordering – the button at the bottom right, the option on
                         every product, and the option in the cart all
                         open WhatsApp with the order already written
                         out (items, quantity, total).
  5. Demo settings     – the small "Demo settings" link in the footer
                         lets you change the store name, currency and
                         WhatsApp number live, so you can see the order
                         message arrive in your own WhatsApp.


IMPORTANT NOTES
----------------------------------------------------------
• Demo mode only. No real payment is taken and no order is stored.
  On the live store, payments run through Shopify's hosted, secure,
  PCI-compliant checkout (UPI, cards, netbanking, wallets, COD).

• Product names, prices and images are placeholders, used to show
  layout and behaviour. Your own logo, product photography, prices
  and copy are added during the first phase of the project.

• Currency is currently set to Indian Rupee (INR) and the WhatsApp
  number is a placeholder. Both are one-line changes once you confirm
  them — tell me the currency and WhatsApp number and I will update
  the demo before it goes any further.

• The WhatsApp ordering is built with native WhatsApp links, so there
  is no monthly app subscription for it. There is no paid app required
  anywhere in this design.
